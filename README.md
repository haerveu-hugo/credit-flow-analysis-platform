# 征信分析 + 流水统计本地平台

这是一个本地运行的征信、银行流水、综合资料和财务报表分析平台。所有上传文件默认只在本机处理，适合用于客户资料初筛、银行流水汇总、征信结构化分析、财报趋势分析和综合报告生成。

## 功能

- 征信分析：支持 PDF、图片，多文件分别出报告和批量汇总。
- 流水统计：支持 PDF、Excel、图片，多文件和同账户汇总，支持密码文件。
- 综合分析：可上传包含征信和流水的文件夹或多文件，自动识别类型并生成综合报告；非征信/非流水文件会跳过。
- 财报分析：支持 PDF、Excel、图片，结合行业、经营范围和企业实际描述进行分析。
- 本地下载：支持 PDF、Word、Excel 等结果导出。

## 隐私说明

本仓库不包含任何客户原始资料、OCR 文本、分析报告或导出结果。`.gitignore` 已默认排除 `tmp/`、客户 PDF/Excel/图片、生成报告和大体积本地依赖，避免误提交敏感数据。

如果你要把自己的客户样本加入仓库，请先做脱敏处理。

## 本地运行

macOS 双击运行：

```bash
scripts/start_local.command
```

启动后打开统一入口：

```text
http://127.0.0.1:8791/
```

各模块默认端口：

- 征信分析：`http://127.0.0.1:8789/`
- 流水统计：`http://127.0.0.1:8790/`
- 统一入口：`http://127.0.0.1:8791/`
- 综合分析：`http://127.0.0.1:8792/comprehensive`
- 财报分析：`http://127.0.0.1:8793/financial`

停止平台：

```bash
scripts/stop_local.command
```

## 依赖说明

首次运行会创建 `.venv` 并安装 `requirements.txt`。PDF 转图片依赖 Poppler；如系统没有安装，可在 macOS 上使用：

```bash
brew install poppler
```

如果 Poppler 安装在非标准位置，可设置：

```bash
export POPPLER_BIN="/path/to/poppler/bin"
```
